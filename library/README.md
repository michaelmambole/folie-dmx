# Bibliothèque de fixtures

rangés par constructeur : `library/<constructeur>/<modèle>.json`.

| Fichier | Origine |
|---|---|
| `martin/rush-mh-2-wash.json` | Open Fixture Library (licence MIT, voir ci-dessous) |
| `martin/rush-mh-6-wash.json` | Écrit pour Folie-DMX d'après le manuel Martin, révision D (absent d'OFL) |
| `showtec/sunstrip-active-mkii.json` | Open Fixture Library (licence MIT) |
| `robe/robin-ledbeam-350.json` | Écrit d'après la table DMX Robe v1.4 (absent d'OFL) |
